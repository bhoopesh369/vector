How timing works

Video time = session time × clock rate + camera offset. Two matching events can estimate clock drift using Anchor 1 and Anchor 2. Each watch session keeps its own camera alignment; uncheck cameras that do not cover it. Session zero is the first IMU row. The combined recording preserves the gap between the two watch sessions. Playback follows the full shared watch timeline. Each video plays only inside its aligned clip interval; missing video or IMU samples are shown as empty regions. Buffering pauses playback.

1200 Hz / 120 fps is roughly 10 readings per source frame. Every valid IMU row is retained; charts use per-pixel min/max envelopes. Values show the nearest timestamp. Browser decoding and display refresh can limit frame presentation; this is manual alignment, not hardware synchronization.
